# 3D Model Directory

Place the 3D floating island model in this directory:

- **Target File Path:** `public/models/home-island.glb`
- **Format:** Binary GLTF (`.glb`)
- **Origin & Scale:** Centered at `(0, 0, 0)`, island diameter roughly 8-12 units.
- **Interactive Mesh Names:**
  - Hero's House: name node or mesh `HeroHouse` or containing `house`
  - Training Grounds: name node or mesh `TrainingArea` or containing `training`
  - Small Farm: name node or mesh `FarmArea` or containing `farm`
  - Party Gathering: name node or mesh `PartyCamp` or containing `party`

When `home-island.glb` is placed in this folder, the website foundation will automatically detect and load it seamlessly in place of the foundation placeholder.
